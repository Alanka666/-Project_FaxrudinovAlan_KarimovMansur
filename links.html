LESSON 4

Links

Links are what make the web a web. The anchor tag, , turns text or other content into a clickable connection to another page, file or section.

The anchor tag

An anchor needs an href attribute, which holds the destination address.

Example
<a href="https://example.com">Visit Example</a>

Relative vs. absolute links

An absolute link includes the full address, starting with https://. A relative link only gives the path to a file within your own site, such as lessons/basics.html - which is exactly how this site links between its own pages.

Opening a link in a new tab

Adding target="_blank" opens the link in a new browser tab instead of replacing the current page.

Example
<a href="https://example.com" target="_blank">Open in new tab</a>

Linking to a section on the same page

Give an element an id, then link to it with a # followed by that id.

Example
<a href="#contact">Jump to contact</a>
...
<h2 id="contact">Contact</h2>
