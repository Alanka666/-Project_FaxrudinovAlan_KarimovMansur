Test Your Knowledge

Pick an answer for each question. You will see instantly if it is right.

1. Which tag creates the most important heading on a page?

<h1> is the top-level heading (use it once per page). <h6> is the least important one, and <head> / <header> are different tags.

2. Which attribute gives an image a text description for screen readers?

alt is the alternative text. It is read aloud by screen readers and shown if the image fails to load. src only points to the image file.

3. Which tag creates a numbered (ordered) list?

<ol> means "ordered list" and numbers its items automatically. <ul> makes bullet points, and <li> is a single item inside either list.

4. How do you make a link open in a new browser tab?

Adding target="_blank" to an <a> tag opens the destination in a new tab.

5. Which tag defines a header cell in a table?

<th> is a header cell, <td> is a normal data cell and <tr> is a whole row.

6. Which semantic tag is meant for a block of navigation links?

<nav> tells browsers and screen readers that its content is navigation. A plain <div> has no meaning.
