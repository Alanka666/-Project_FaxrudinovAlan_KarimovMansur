LESSON 5

Images

The tag embeds a picture into a page. Unlike most tags, it is self-closing - the image comes from a file, so there is no inner content to wrap.

Adding an image

The src attribute points to the image file, and the alt attribute provides a text description.

Example
<img src="images/html-logo.svg" alt="WebStart logo">
⚠️

Never skip alt. Screen readers read it aloud for visually impaired visitors, and browsers show it if the image fails to load.

Controlling image size

The width and height attributes (in pixels) reserve space for the image before it finishes loading, which prevents the page from jumping around.

Example
<img src="photo.jpg" alt="Sunset over the hills" width="600" height="400">

Images with a caption

<figure> groups an image with a <figcaption> that describes it.

Example
<figure>
<img src="photo.jpg" alt="Sunset over the hills">
<figcaption>A sunset over the hills</figcaption>
</figure>
