LESSON 7

Tables

Tables display data in rows and columns. They should be used for genuinely tabular data - not for arranging a page's layout, which is CSS's job.

Basic table structure

<table> wraps the whole table, <tr> defines a row, and <td> defines a single cell within that row.

Example
<table>
<tr>
<td>Lesson</td><td>Status</td>
</tr>
<tr>
<td>HTML Basics</td><td>Completed</td>
</tr>
</table>

Table headers

<th> marks a cell as a header instead of a regular data cell - browsers bold and center it by default, and it helps screen readers describe the table correctly.

Grouping with thead and tbody

<thead> groups the header row, and <tbody> groups the data rows, which makes larger tables easier to read and style.

Example
<table>
<thead>
<tr><th>Lesson</th><th>Status</th></tr>
</thead>
<tbody>
<tr><td>HTML Basics</td><td>Completed</td></tr>
</tbody>
</table>
💡

Use colspan or rowspan on a cell to make it span across multiple columns or rows.

Quick Quiz

Check what you just learned - pick an answer for each question.

1. Which tag defines a table row?

<tr> is a table row. Cells go inside it: <td> for data and <th> for headers.

2. Which attribute makes a cell stretch across several columns?

colspan merges columns. Its sibling rowspan merges rows instead.
