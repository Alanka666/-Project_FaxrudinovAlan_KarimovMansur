Working with Text

Most of a web page is text. HTML gives you tags for paragraphs, emphasis, line breaks and quotations so content stays both readable and meaningful to browsers.

Paragraphs

The <p> tag defines a paragraph. Browsers automatically add space above and below each one.

Example
<p>HTML is the backbone of every web page.</p>

Bold and italic text

<strong> marks text as important (shown bold by default), and <em> marks text as emphasized (shown italic by default).

Example
<p>This step is <strong>very important</strong>.</p>

Line breaks and horizontal rules

<br> inserts a single line break inside text, and <hr> draws a horizontal line to separate content. Both are "void" elements - they have no closing tag because they don't wrap any content.

💡

Don't use <br> to add space between paragraphs - use a new <p> instead, and control spacing with CSS.
