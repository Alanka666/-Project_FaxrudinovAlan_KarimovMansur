Document Structure

Before writing any visible content, it helps to understand the two main regions of an HTML document: the , which holds information about the page, and the , which holds everything visitors actually see.

The <head> section

Nothing inside <head> is displayed on the page directly. It usually contains the character set, the page title, the viewport setting, and links to stylesheets.

Example
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>My Website</title>
<link rel="stylesheet" href="style.css">
</head>

The <body> section

Everything inside <body> is rendered in the browser window: headings, text, images, links, forms and so on. A page has exactly one <body>.

Headings: <h1> to <h6>

Headings create a hierarchy of titles, from <h1> (most important, used once per page) down to <h6> (least important).

⚠️

Don't choose a heading level because of how big it looks - choose it because of where it sits in the page's outline. Use CSS to change the visual size instead.
