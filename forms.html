LESSON 8

Forms

Forms collect input from visitors - names, messages, choices - and are built from the <form> tag plus a set of input controls inside it.

The form tag

<form> wraps every control that belongs to the same submission, such as a contact form or a search box.

Text input and labels

<input> creates a form control; its type attribute decides what kind of control it is. Always pair an input with a <label> so visitors (and screen readers) know what it's for.

Example
<form>
<label for="name">Your name</label>
<input type="text" id="name" name="name">

<label for="email">Email</label>
<input type="email" id="email" name="email">

<button type="submit">Send</button>
</form>

Other common controls

  • <textarea> - a multi-line text box
  • <select> with <option> - a dropdown menu
  • <input type="checkbox"> - a yes/no toggle
  • <input type="radio"> - one choice from a group
⚠️

The for attribute on a label must match the id of its input exactly, or clicking the label won't focus the field.

Quick Quiz

Check what you just learned - pick an answer for each question.

1. Which attribute connects a <label> to its input?

The for value must match the input's id. Then clicking the label focuses the field.

2. Which tag creates a multi-line text box?

<textarea> is a multi-line field, great for messages. A normal text input holds only one line.
