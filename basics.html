HTML Basics

HTML (HyperText Markup Language) is the language used to build the structure of every web page. It is not a programming language - it is a markup language, meaning it describes the content of a page using tags.

What is a tag?

A tag is a piece of markup wrapped in angle brackets, like <p>. Most tags come in pairs: an opening tag and a matching closing tag (written with a forward slash), with the actual content placed between them.

Example
<p>This text is a paragraph.</p>

Your first HTML document

Every HTML page shares the same minimal skeleton: a <!DOCTYPE html> declaration, an <html> element, and inside it a <head> and a <body>.

index.html
<!DOCTYPE html>
<html lang="en">
<head>
<title>My Website</title>
</head>
<body>
<h1>Hello, world!</h1>
</body>
</html>
💡

Tag names are case-insensitive, but the convention is to always write them in lowercase.

Elements vs. attributes

An element is a tag plus its content. An attribute gives extra information about an element and is written inside the opening tag, as a name="value" pair - for example, lang="en" above tells the browser the page's language.

Quick Quiz

Check what you just learned - pick an answer for each question.

1. What does HTML stand for?

HTML is HyperText Markup Language. It is a markup language that describes the structure of a page, not a programming language.

2. Which declaration goes at the very top of an HTML5 document?

<!DOCTYPE html> tells the browser to use modern HTML5 rules. It always comes first, before the <html> element.
