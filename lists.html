LESSON 6

Lists

HTML provides three kinds of lists: unordered (bullet points), ordered (numbered), and description lists for term/definition pairs.

Unordered lists

<ul> creates a bullet-point list, with each item wrapped in <li> (list item).

Example
<ul>
<li>HTML</li>
<li>CSS</li>
<li>JavaScript</li>
</ul>

Ordered lists

<ol> works the same way but numbers the items automatically instead of using bullets.

Example
<ol>
<li>Open your code editor</li>
<li>Create a new file</li>
<li>Save it as index.html</li>
</ol>

Nested lists

A list can be placed inside an <li> to create sub-items, which is how this site's own lesson navigation could be structured if it had sub-topics.

Description lists

<dl> pairs a term (<dt>) with its definition (<dd>) - useful for glossaries.

Example
<dl>
<dt>HTML</dt>
<dd>The markup language used to structure web pages.</dd>
</dl>
